**伤疤**(Scar)是你[[圣域]]中原有之物在它所达到的层级上被摧毁后的形态。宅邸是活的，所以伤疤就是创伤：它会让你失去它的[[圣域#地块|地块]]、它的[[mood capacity|心境容量]]和它在[[Coherence|凝聚度]]中的份额，并带有与那个房间原本所给予之物相对应的**减益**(malus)。

## 什么会留下伤疤

每个层级都会留下各自的废墟：

| 层级                    | 伤疤                         |
| ----------------------- | ---------------------------- |
| [[扎根阶梯#松散\|松散]] | 无                           |
| [[扎根阶梯#陈设\|陈设]] | 墙上的痕迹                   |
| [[扎根阶梯#独室\|独室]] | 一间烧毁的房间               |
| [[正殿]]                | 一座坍塌的大厅，周围房间下陷 |

记忆的正殿还会在身体上留下印记。松散的物品和[[Belief stages|沉吟]]不留下伤疤。

- **[[连根拔起]]**：正殿以下的连根拔起只有失手时才留下伤疤；正殿总会留下伤疤，即使手法干净。
- **[[倾诉]]**：倾诉陈设过快有留下伤疤的风险；过慢则有被打断的风险。
- **信念**被摧毁时，结果与摧毁它的形态相同：拆掉的书柜在墙上留下痕迹，烧毁的房间在建筑上留下伤疤，教条的神龛会在其大厅坍塌时遭到毁损（见[[Belief|信念]]）。

## 减益

| 减益     | 效果                                                                 | 起始层级 |
| -------- | -------------------------------------------------------------------- | -------- |
| 晦暗     | 相邻房间的[[Hold\|扎根度]]更快地被[[Forgetting\|遗忘]]消磨            | 陈设     |
| 醒来代价 | 被打扰的[[休息]]恢复得更少                                           | 独室     |
| 隐痛     | 那种情感的[[内心之声]]诉说着失去，牵动你的心境                       | 独室     |
| 缺失     | 效果原本所在之处留下一种挥之不去的虚弱：被拔除的鳃让你在水下喘不过气 | 正殿     |

坍塌的房间也带有伤疤的减益（见[[开裂与坍塌]]）。

## 愈合

伤疤分三个阶段愈合：**新伤**、**结疤**和**愈合**。

- **[[Unmaking|消解]]**：能迅速清除创伤，代价是你自己的凝聚度。若处理不慎，它会蔓延到周围的房间。
- **时间与帮助**能让它合拢：小伤疤在长休中愈合，较大的则需要有人照料。
- **重建**能把它填满：在废墟上扎根一样同种情感的新东西。

愈合可能失败。用错了情感或操之过急重建的伤疤会长歪，留下一丝微弱的减益；疤痕组织在触发之下会像原来的伤口一样重新裂开。只有愈合的伤疤才是安全的，而它仍会留下痕迹，比如横跨大理石的铅制扣钉。
