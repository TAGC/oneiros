在 Oneiros 的**宇宙观**(Cosmology)中，[[做梦者]]在太初做了一个统一的梦。这个梦碎裂了，并且仍在碎裂：整个世界的合运动朝着「梦」的终结而去，远远超出任何玩家所能及。

## 同一意志的碎片

每个存在和每个地方都是那个意志的一块[[碎片]]。单独使用时，“碎片”指世界的各个区域：被[[被铭记|铭记]]得最牢固、因而最稳定的部分。它们之间是[[接缝]]，即被铭记较少的土地，[[遗忘]]的黑暗在那里占据上风。

只有世界的结构朝着一个方向碎裂。建立在其上的历史遵循与我们相似的模式：意志既会分裂，也会结合，伟大的王国在任何时代都可能兴起。

## 世界的力

每个意志都有自己的[[力]]（Kraft，美因兰德的用语），世界的力就是所有意志之力的总和。力从不被创造，只在相反的外显运动相互湮灭时才会损失（见[[力守恒]]）。

世界的力在万古之中逐渐减少，慢到大多数居民都察觉不到。相邻碎片相反的[[余情]]沿着接缝相遇并湮灭，因此接缝闪烁着[[清明]]的微光；它与遗忘一起，使世界的力逐渐耗损。

## 各术语的关系

| 术语 | 它的角色 |
| --- | --- |
| [[做梦者]] | 其碎裂之梦即是世界的存在 |
| [[梦境之地]] | 那个梦，唯一的共享世界 |
| [[碎片]] | 做梦者意志的任何片段；单独使用时指一个稳定的区域 |
| [[接缝]] | 碎片之间被铭记较少的土地，闪烁着清明的微光 |
| [[力]] | 一个意志的运动之量；世界的力是所有意志之力的总和 |
| [[力守恒]] | 力为何只会衰减 |
| [[余情]] | 被释放的力，其相反者沿接缝湮灭 |
| [[遗忘]] | 黑暗，在接缝中占据上风 |

[[Other ideas|其他想法]]还列出了另一个构想，并非定案：世界生成或许会构建一棵分裂树，每次分裂都沿着一块碎片最强的张力，把它分成一个向外的姊妹和一个向内的姊妹，而力在每一代都会减弱。
