**光束**(beam)是沿一条线瞬间命中的[[Delivery|投送]]。它可以一闪而过，也可以[[Channelling|引导]]。它没有飞行时间，所以一旦发出就无法躲开；明显的蓄势让它保持公平。

## 形状

[[Composition|构成]]决定光束的效果，[[Adverb|副词]]决定它的形状。没有副词时，它是一道普通的直线光束。

| 副词 | 形状 |
| ---- | ---- |
| 广泛地 | 分叉 |
| 稳定地 | 在它的线上停留数个回合 |
| 遥远地 | 越过掩体划出长长的弧线，稍迟片刻才落下 |
| 全然地 | 连锁到目标周围的一切 |
| 缓慢地 | 渗透：起初很弱，之后沿线持续灼烧 |
| 短暂地 | 闪烁：快速而廉价的一闪，留出溜走的片刻 |
| 突然地 | 一闪（见[[Adverb#突然地]]） |
| 深深地 | 收窄并寻找一个目标，穿透最深 |

## 串联副词

[[Casting#串联副词|串联副词]]按顺序展开：`· 远 广`先划弧再分叉；`· 广 远`先分叉，再让每一支各自划弧。相反的副词相互抵消，重复的副词会加强。每个副词都带来它自己的代价变化，并占用一个[[Chain|串]]的位置。

## 穿透

光束能穿透多远，取决于它的[[Intensity|强度]]和它所穿过的事物。

## 光束角力

两道相反的光束相遇时，会在交汇点湮灭，不断喷溅出[[Lucidity|清明]]。较强的一股会把交汇点推向较弱的施法者。
