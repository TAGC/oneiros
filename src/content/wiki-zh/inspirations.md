[[Oneiros]] 背后的**灵感来源**(inspirations)来自游戏、小说和哲学。以下是它从每一个那里取用的东西。

| 来源 | 我们取用的东西 |
| ---- | -------------- |
| 《Caves of Qud》 | 系统深度、层层叠叠的历史、[[Mutation\|变异]]、烹饪 |
| 洛夫克拉夫特的“梦境系列”（Dream Cycle） | 一个共享的梦境世界，以及“梦境之地”（the Dreamlands）这个名字 |
| 《极乐迪斯科》（Disco Elysium） | 作为[[Inner voices\|内心之声]]的技能；思维内阁 |
| 布兰登·桑德森 | 由其限制来定义的魔法；奇才；储存与[[Burning\|燃烧]] |
| 《魔能》（Magicka） | 串联元素，对立的元素相互抵消 |
| 《时光之轮》（The Wheel of Time） | 引导一个危险的源头 |
| 《灵魂摆渡人》（Spiritfarer） | 照顾他人，学会放手 |
| 菲利普·美因兰德 | 万物都是[[Will in motion\|运动中的意志]]；感受即运动；[[Quality of the will\|意志的品质]]；一个走向终结的世界 |
| 布鲁斯·布隆伯格，《Old Tricks, New Dogs》 | 争夺自由度的行为，以及主要、次要和元命令 |
| 《法师：飞升》（Mage: The Ascension） | 现实会反抗明目张胆的魔法 |
| 《Noita》、《塞尔达传说：旷野之息》 | 系统化的世界交互 |
| 《Superhot》 | 只有你动，时间才会流动 |
| 《Wildermyth》 | 由部件拼成、随时间变化的角色 |
| 《Brogue》 | 富有氛围的光照与效果 |
| 《矮人要塞》（Dwarf Fortress） | 带有历史模拟的世界生成；分层的身体部位和服装 |
| 《飓光志》（The Stormlight Archive） | 塑造世界节奏的风暴 |

## 体现在哪里

- 《Caves of Qud》：本作是一款继承其精神的系统驱动角色扮演游戏；记忆是一切价值的根本，就像 Qud 里的水（见[[经济]]）；[[Attention|注意]]的运作类似 Qud 的微光值（glimmer）；效果语法沿用 Qud 的烹饪（见[[制作]]）。
- 布隆伯格：事物如何对法术作出反应，每种事物都有各自的自由度（见[[Casting|施法]]和[[Kind|种类]]）。
- 《矮人要塞》：在任何[[遐梦]]出现之前，世界就已被梦出，它的历史也已模拟完毕（见[[内容生成]]）。
- 《Superhot》：只有你动，时间才会流动（见[[Dreamlands|梦境之地]]）。
