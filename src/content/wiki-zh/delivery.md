**投送**(delivery)是法术的[[Force|力]]去往何处。它是法术的三条轴之一（见[[Casting|施法]]）。

## 三条轴

| 轴 | 说明 |
| -- | ---- |
| [[Composition\|构成]] | 法术做什么 |
| [[Adverb\|副词]] | 它如何作用，以及它的形状 |
| 投送 | 它的力去往何处 |

投送不由[[Emotion|情感]]组成。它不在[[Chain|串]]中，不占串的位置，自身也没有价格。

## 路径决定代价

投送的代价来自它的路径。[[Bolt|法箭]]会把力损耗在空气中，[[Aura|气场]]会泄漏，[[Touch|触碰]]则毫无损耗。价格预览会显示路径上预计的损耗（见[[Casting#代价与预览|施法]]）。

## 选择投送

你通过输入来选择投送，具体方式取决于平台：轻点为单次施法，按住则[[Channelling|引导]]。读法会把投送与情感分开显示（见[[Casting#解读法术|解读法术]]）。

## 各种投送

| 投送 | 去向 |
| ---- | ---- |
| [[Aura\|气场]] | 进入你周围的一片区域 |
| [[Bolt\|法箭]] | 作为一发飞行的射击 |
| [[Beam\|光束]] | 沿一条线瞬间抵达 |
| [[Touch\|触碰]] | 进入你正触碰的事物 |
| [[#灌注投送\|灌注]] | 进入一件事物，直到触发条件将它释放 |

任何投送都可以是单次的或[[Channelling|引导]]的。

“施放”不是一种投送，因为[[Casting|施法]]指的是制作任何法术。

## 灌注投送

陷阱、地雷、[[Potions|药剂]]和食物同属一族：灌注之物把一个法术保存在自己的[[Mood|心境]]中，直到触发条件将它释放。

| 灌注之物 | 由谁释放 |
| -------- | -------- |
| 药剂 | 喝下它的人，稍后才把法术吸收进去：一次延迟的[[Touch|触碰]] |
| 陷阱 | 受害者的触发 |
| 地雷 | 施法者的触发 |

触发条件是用[[Crafting#效果语法|效果语法]]（一个基础效果、一个触发条件和一个触发效果）制作出来的变量：接触、靠近、打开、一道影子落下，等等。[[Crafting#效力预算|效力预算]]按它触发的频率和强弱来定价。每个[[Kind|种类]]都有自然的触发条件：门槛在被打开时，光在有影子掠过时，水在被搅动时，地面在被踩踏时。

## 灵感来源

《魔能》(Magicka)的施法类型（向前、范围、自身和武器）启发了这条轴。《上古卷轴5》(Skyrim)的 Creation Kit 也用“Delivery”指同一条轴（Self、Touch、Aimed、Target Actor、Target Location），并把它与 Casting Type 分开。灌注一族借鉴了《魔能》的地雷（护盾加生命或奥术），以及《流放之路》(Path of Exile)：它的陷阱靠靠近或时间触发，地雷则靠手动引爆。
