**希腊名称**(Greek names)属于游戏中最古老的事物。希腊语是深处的语言，而不是世界的外观：它为最古老、属于宇宙层面的事物（Oneiros、[[Temenos|圣域]]、[[无定]]、[[Oceanus|俄刻阿诺斯]]、摩涅莫绪涅、勒忒）以及无定的单位命名。

## 最古老的事物

| 名称 | 所指 |
| ---- | ---- |
| Oneiros | 游戏本身（见 [[Oneiros]]） |
| 圣域（Temenos） | 你心灵的宅邸（见[[Temenos\|圣域]]） |
| 无定（Apeiron） | 梦的无形之质（见[[无定]]） |
| 俄刻阿诺斯（Oceanus） | 承载无定、环绕世界的大河（见[[Oceanus\|俄刻阿诺斯]]） |
| 摩涅莫绪涅（Mnemosyne） | 只有名字，尚无作用 |
| 勒忒（Lethe） | 只有名字，尚无作用 |

无定的单位都是希腊的器皿：[[库阿托斯]]（一勺）、科堤勒（一杯）、科乌斯（一壶）、安佛拉（储物罐）和皮托斯（大储物瓮）。

## 典故名称

有三个希腊语名称只用于典故，每个都指一个已经有通俗名称的世界：

| 典故名称 | 通俗名称 | 是什么 |
| -------- | -------- | ------ |
| 共同世界（Koinos kosmos） | [[Dreamlands\|梦境之地]] | 共享的世界 |
| 私人世界（Idios kosmos） | [[Inner world\|内在世界]] | 一个意志的私人世界 |
| 居间（Metaxy） | [[交会之地]] | 两个内在世界相交的中间地带 |

同样的情感色彩在梦境之地和你的内在世界中都成立（见[[Emotion|情感]]）。

## 不是世界的外观

希腊名称并不会让世界变成希腊风格。日常的地方、人物和遐梦都遵循梦里的样子，而且没有希腊诸神：[[Dreamer|做梦者]]是唯一类似神的存在。古典风格如何塑造圣域，见[[美术风格]]。
