**副词**(adverb)是决定法术如何作用的[[Emotion|情感]]，写在分隔符之后。每个法术都是一个[[Composition|构成]]，加上一种用作副词的情感（见[[Casting|施法]]）。

## 八个副词

| 情感 | 副词   |
| ---- | ------ |
| 喜悦 | 广泛地 |
| 勇气 | 稳定地 |
| 希望 | 遥远地 |
| 爱   | 全然地 |
| 悲伤 | 缓慢地 |
| 恐惧 | 短暂地 |
| 绝望 | 突然地 |
| 恨   | 深深地 |

短暂地和突然地会减少动词所需的[[Material|材料]]，稳定地、全然地、遥远地和广泛地则会增加它。

## 规则

任何情感都可以作副词；以动词的相反情感作副词，会相抵成为一个[[Lucidity|清明]]驱散法术；副词与动词共用[[Chain|串长上限]]。完整的规则，包括串联副词，见[[Casting#副词|施法]]。

> [!CONFLICT]
> 表格中缓慢地的例子曾是“睡眠：恨，缓慢地：狼的恨意不知不觉地流失”。睡眠魔法已存档（见[[Archived ideas|已存档的构想]]）。在此问题解决之前，表格依照 Vision 为它暂定的归宿，改为“消解：恨，缓慢地”。

> [!OPEN]
> 缓慢地的例子假定[[Unmaking|消解]]是旧睡眠魔法的归宿，而 Vision 把这一点标为暂定。

> [!CONFLICT]
> 表格中深深地的例子曾是“喜悦，深深地：抵消一扇门中的悲伤，而不是它周围神龛中的”。Vision 说内蕴的感受从不湮灭，所以一扇门可以同时感到喜悦和悲伤，而且“落在一个意志上的法术会加入它的心境，即使与它的相反情感并存”（见[[Held and manifest|内蕴与外显]]）。在此问题解决之前，表格改为“喜悦，深深地：一扇门亮了起来，而不是它周围的神龛”。
