**副词**(adverb)是决定法术如何作用的[[Emotion|情感]]，写在分隔符之后。法术是一个[[Composition|构成]]，可带任意数量的副词，也可以不带（见[[Casting|施法]]）。

## 八个副词

| 情感 | 副词   |
| ---- | ------ |
| 喜悦 | 广泛地 |
| 勇气 | 稳定地 |
| 希望 | 遥远地 |
| 爱   | 全然地 |
| 悲伤 | 缓慢地 |
| 恐惧 | 短暂地 |
| 绝望 | 突然地 |
| 恨   | 深深地 |

短暂地会减少动词所需的[[Material|材料]]，稳定地、全然地、遥远地和广泛地则会增加它。突然地是一种折中（见[[#突然地]]）。

## 规则

任何情感都可以作副词；以动词的相反情感作副词，会相抵成为一个[[Lucidity|清明]]驱散法术；副词与动词共用[[Chain|串长上限]]。完整的规则，包括串联副词，见[[Casting#副词|施法]]。

## 突然地

突然地（绝望）是一种折中：

- **价格不变。** 投入的每种情感，代价都和平常一样。
- **一下子全部发生。** 整个法术在一瞬间全部送出。它不能被[[Channelling|引导]]，也不会留下任何余波。
- **更高的上限。** 它抬高[[Intensity|强度]]的上限。
- **超出上限即有损耗。** 超过通常的上限后，超出部分只有一部分进入法术，超得越多，这一部分的比例越小。
- **法术自身迸裂。** 超出部分从法术本身迸出，而不是从施法者身上。

这符合它“一下子全部发生，随即结束”的方式：绝望放弃了克制，法术在自身的重负下崩塌。它的意象来自《迷雾之子》(Mistborn)中的硬铝；借用的是构想，而不是名称。
