你的角色由**意志的品质**(Qualities of the will)界定，这出自菲利普·美因兰德的成对对立品质：嫉妒与善意、残忍与仁慈、怯懦与勇敢、忠诚与虚伪，等等。品质决定哪些[[Emotion|情感]]对你来说最为自然：你的[[mood|心境]]停在哪里，又朝哪个方向漂移。事物也有品质（见[[#事物的品质]]）。

品质之上是你的[[temperament|气质]]，它影响哪些品质容易养成，但从不禁止任何一种，因为每个人身上都带着每一种品质的种子。

## 深度

每种品质都有一个深度，会随运用而加深，也会消退，留下残迹。听从一个[[内心之声]]，会加深那句话背后的品质。

滋养某种情感的品质有多深，决定了：

- **该情感所在楼层的地块**，位于你的[[圣域]]中（见[[圣域#地块|地块]]）；
- **你能以多高的强度**施放它。品质限制一个法术能有多强烈；[[mood capacity|心境容量]]限制你有多少某种情感可供花费（见[[Intensity|强度]]）。

## 品质塑造什么

- **你的宅邸。** 意志的品质为整座圣域赋予风格（见[[品质风格]]）。
- **你的声音。** 一个内心之声想要什么，来自滋养它的品质（见[[内心之声]]）。
- **你的反应。** 品质决定一个[[motive|动机]]会引发哪种反应。
- **你的信念。** 一条信念的亲和性，即它能通过[[dwelling|沉思]]吸纳的情感，由它的依据和你的品质决定。

## 抗性

一个意志的品质让它抵抗这些品质所滋养的情感造成的伤害，并且只惧怕其中每一种的相反情感。多种品质会叠加：一个同时有嫉妒和残忍的意志（两者都滋养恨），会强烈地抵抗恨，并明显地惧怕爱。这一点是暂定的。

## 事物的品质

每一种类的事物都有品质，从下面这同一张列表中取用合适的一部分。个体可以与它的[[Kind|种类]]不同。品质让事物的心境有所倾斜，并决定它的[[Grain|本性]]；它们从不限制事物能怀有哪些情感。

以下取用只是建议，尚未确定：

| 种类 | 品质 |
| ---- | ---- |
| 火 | 贪婪、勇敢 |
| 水 | 可塑、温顺 |
| 气与天气 | 可塑、虚伪 |
| 生长 | 不屈、纵情 |
| 固体 | 刚硬、冥顽 |
| 门槛 | 关着时冥顽，开着时坦诚 |
| 光 | 坦诚、慷慨 |
| 生物 | 依物种而定 |

在美因兰德的哲学中，每一件事物都是一个个体的意志，但这些有名称的品质来自他对人类意志的研究（这一解读尚未核实，约见《救赎哲学》第 54 页）。把它们赋予事物，是游戏自己的选择。
